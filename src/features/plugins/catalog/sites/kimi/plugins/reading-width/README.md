# Kimi · Comfortable Reading Width

Gives Kimi one centered, adjustable reading column (600-1600 px, default
1000 px). Kimi caps its conversation list at 800 px and its composer at
768 px; this plugin gives both the same width, so the composer lines up under
the column, and leaves the sidebar at its native size. Both shrink to the
available chat area with 20 px side gutters.

Disable the plugin to restore the native 800 px column and 768 px composer. The width is a normal
Voyager plugin setting and is stored with the rest of the plugin state.

This is a declarative plugin: pure CSS and a typed setting interpreted by
Voyager's bundled plugin engine. It does not execute remote JavaScript or load
external resources.
